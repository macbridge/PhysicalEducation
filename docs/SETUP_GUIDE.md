# 初期設定マニュアル（生徒向け）

体育ラーニングの記録は、**あなた自身の Google スプレッドシート**に保存されます。
最初に一度だけ、次の手順で準備をしてください（所要時間：約10分）。

## 1. スプレッドシートを用意する
1. 学校の Google アカウントでログインする。
2. 先生から配布されたテンプレートのスプレッドシートを開き、「ファイル > コピーを作成」で自分のドライブにコピーする。
   （テンプレートがない場合は、新しいスプレッドシートを作成してください）

## 2. スクリプトを貼り付ける
1. コピーしたスプレッドシートで「拡張機能 > Apps Script」を開く。
2. 最初からある `function myFunction() {}` をすべて消す。
3. 先生から配布された `gas_backend.gs` の内容をすべて貼り付け、💾（保存）を押す。
   （テンプレートをコピーした場合は、すでに入っているのでこの手順は不要です）

## 3. 初期化する
1. 画面上部の関数の選択欄で `setup` を選び、「実行」を押す。
2. 「承認が必要です」と表示されたら「権限を確認」→ 自分のアカウントを選び →「許可」。
   - 「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」を押す。
     自分で作ったスクリプトなので問題ありません。
3. スプレッドシートに `Records` と `Profile` のシートができていれば成功。

## 4. 合言葉を決める
1. Apps Script 画面左の ⚙「プロジェクトの設定」を開く。
2. 一番下の「スクリプト プロパティ」で「スクリプト プロパティを追加」。
   - プロパティ：`TOKEN`
   - 値：自分だけの合言葉（英数字8文字以上がおすすめ。他の人に教えない）
3. 「スクリプト プロパティを保存」を押す。

## 5. ウェブアプリとして公開する
1. 右上の「デプロイ > 新しいデプロイ」を押す。
2. ⚙（種類の選択）で「ウェブアプリ」を選ぶ。
3. 次のように設定して「デプロイ」。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 表示された「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）をコピーする。

## 6. サイトに登録する
1. 体育ラーニングの「設定」を開く。
2. ウェブアプリURL と 合言葉 を入力し「保存して接続テスト」。
3. 「接続できました」と表示されれば完了です。

## うまくいかないとき

| 表示されるメッセージ | 確認すること |
|---|---|
| GASから正しい応答がありません | 手順5で「アクセスできるユーザー」が「全員」になっているか |
| 合言葉が正しくありません | 手順4の TOKEN と、サイトに入力した合言葉が一致しているか |
| スクリプトプロパティ TOKEN が設定されていません | 手順4のプロパティ名が `TOKEN`（大文字）になっているか |
| GASに接続できません | URLの最後が `/exec` になっているか、ネットワークにつながっているか |

> スクリプトを修正したときは「デプロイ > デプロイを管理 > ✏編集 > バージョン：新バージョン」で更新すると、URLを変えずに反映できます。

## 先生へ（環境の確認事項）
- 学校の Google Workspace の管理設定によっては、「アクセスできるユーザー：全員」が選べない場合があります。
  その場合は Workspace 管理者に Apps Script の公開設定を確認してください。
- テンプレートのスプレッドシートにあらかじめ `gas_backend.gs` を入れておくと、生徒は手順2を省略できます。
