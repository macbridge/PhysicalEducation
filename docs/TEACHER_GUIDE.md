# 教員向けマニュアル

体育ラーニング（https://macbridge.github.io/PhysicalEducation/）を授業で使うための手引きです。
生徒向けの準備手順は [初期設定マニュアル（SETUP_GUIDE.md）](SETUP_GUIDE.md) にあります。

## 1. しくみ

```
生徒の端末（Chromebook / iPad など）
   │  体育ラーニングのページ（GitHub Pages）
   ▼
生徒ごとの GAS ウェブアプリ（合言葉で保護）
   ▼
生徒ごとの Google スプレッドシート（Records / Profile シート）
```

- 記録は**生徒一人ひとりの Google スプレッドシート**にだけ保存されます。サイト（GitHub）や他の生徒のシートには保存されません。
- ブラウザに保存されるのは「接続先の URL と合言葉」だけです（デモモードでは記録もその端末のブラウザに保存）。
- サーバーやデータベースは使っていないため、費用はかかりません。

## 2. 事前準備（先生）

### 2-1. Google Workspace の設定を確認する
生徒が自分のスクリプトを「ウェブアプリ・アクセスできるユーザー：全員」でデプロイできる必要があります。
学校の Workspace でこの公開が制限されている場合は、Workspace 管理者に Apps Script の公開設定を確認してください。
先生のアカウントで一度 [SETUP_GUIDE.md](SETUP_GUIDE.md) の手順を最後まで試し、「接続できました」と表示されることを確認しておくと安心です。

### 2-2. テンプレートのスプレッドシートを作る（推奨）
1. 新しいスプレッドシートを作成し、名前を「体育ラーニング記録（名前）」などにする。
2. 「拡張機能 > Apps Script」を開き、[gas_backend.gs](../gas_backend.gs) の内容をすべて貼り付けて保存する。
3. 関数 `setup` を実行し、`Records` と `Profile` シートができたことを確認する。
4. **合言葉（スクリプトプロパティ `TOKEN`）は設定しない**でおく（生徒が各自で決めるため）。
5. Google Classroom などで「各生徒にコピーを作成」として配布する。

テンプレートを使うと、生徒は初期設定マニュアルの手順2（スクリプトの貼り付け）を省略できます。
**デプロイ（ウェブアプリとして公開）はコピーされないため、手順5は生徒が各自で行います。**

## 3. 最初の授業での導入（目安：20〜30分）
1. サイトを開き、「設定 > デモモードで試す」で操作を体験させる（記録してグラフが出るところまで）。
2. 初期設定マニュアルに沿って、各自のスプレッドシートを接続させる。
3. 設定画面に「接続できました」と表示されたことを確認する。
4. 共用の端末を使う場合は、授業の終わりに「接続設定を削除」を押すよう指導する（次の人が記録できてしまうため）。

## 4. 各領域で生徒が行うこと

| 領域 | 生徒が行うこと | 保存される記録 |
|---|---|---|
| A 体つくり運動 | 体力テスト9項目・運動の実施時間を記録、得点表（男女）を選んでレーダーチャートで前回と比較 | 項目ごとの記録 |
| B 器械運動 | 技の系統図で技をタップし「まだ／練習中／できた」をチェック | 技ごとのチェック |
| C 陸上競技 | 種目別の記録（1500m は「分:秒」入力可） | 種目ごとの記録 |
| D 水泳 | 泳法別のタイム、長く泳いだ距離 | 種目ごとの記録 |
| E 球技 | 種目を選び、作戦ボードで話し合い、その日のゲームの個人スタッツと自己評価を記録 | 項目ごとの記録 |
| F 武道 | 柔道・剣道の礼法・基本動作・技をチェック | 技ごとのチェック |
| G ダンス | 観点ごとに自己評価・仲間からの評価（5段階）とコメントを記録 | 観点ごとの評価 |
| H 体育理論 | 単元の解説を読み、確認テスト（5問）を解いて得点を記録 | 単元ごとの得点 |

トップページには、接続済みの生徒の「わたしの記録」（記録の数・領域ごとの要約）が表示されます。

## 5. 生徒の記録を確認する
生徒に、自分のスプレッドシートを先生と**閲覧者**として共有してもらいます（「共有」ボタン → 先生のアドレス → 閲覧者）。

`Records` シートの列は次のとおりです。

| 列 | 内容 |
|---|---|
| id / createdAt | 記録の識別子・保存した日時（自動） |
| domain | 領域（A〜H） |
| metric | 記録の種類（下表） |
| date | 記録の日付 |
| value | 値 |
| unit | 単位 |
| memo | メモ・コメント |

`metric` の読み方：

| 形式 | 意味 | value |
|---|---|---|
| `sprint100`、`grip` など | 数値の記録（A・C・D、H の `unit1`〜`unit3`） | 記録の数値（タイムは秒） |
| `skill:マット:前転` | 技のチェック（B・F） | 0 まだ / 1 練習中 / 2 できた |
| `eval:sosaku:self:1` | ダンスの評価（種類：sosaku 創作 / folk フォーク / rhythm 現代的なリズム、self 自己 / peer 仲間、観点番号） | 1〜5 |
| `stat:basketball:shots` | 球技のスタッツ（種目・項目） | 回数（`selfeval` は自己評価 1〜5） |

チェックや評価は、操作するたびに1行追加されます。同じ技・項目の行が複数あるときは、**日付が最も新しい行**が現在の状態です。
スプレッドシートのフィルタ機能で `domain` や `metric` を絞り込むと見やすくなります。

## 6. 内容を授業に合わせて変える
サイトの内容は GitHub リポジトリ（https://github.com/macbridge/PhysicalEducation）のファイルを編集すると変更できます。
`main` ブランチに反映すると、数分で公開サイトに反映されます。

| 変えたいもの | ファイル |
|---|---|
| 領域の概要・記録項目 | `js/config.js` |
| 各領域の解説・技の一覧・評価観点・テスト問題 | `js/content/<領域>.js`（例：器械運動は `b-kikai.js`） |
| 体力テストの得点表 | `js/fitness.js` |

> **注意：** 記録項目の key、技の名前、評価観点の順番、スタッツの項目 key を変更・削除すると、
> それまでの記録とサイトの表示が結び付かなくなります（シートのデータは消えません）。
> 年度の途中では、追加だけにとどめることをおすすめします。

## 7. 個人情報・安全のために
- 合言葉は生徒本人だけが知っているようにし、ウェブアプリ URL と一緒に他人に教えないよう指導してください。
- 合言葉が漏れた場合は、スクリプトプロパティの `TOKEN` を変更し、サイトの設定画面で新しい合言葉を入力し直します。
- 共用端末では、使い終わったら「設定 > 接続設定を削除」を押します。
- デモモードの記録はその端末のブラウザにだけ残ります。授業の本番の記録には使わないでください。

## 8. 困ったとき

| 状況 | 対応 |
|---|---|
| 接続テストでエラーになる | [SETUP_GUIDE.md の「うまくいかないとき」](SETUP_GUIDE.md#うまくいかないとき) を参照 |
| 記録が表示されない | ヘッダーの「設定」に「未接続」「デモ」の表示がないか確認する |
| スクリプトを更新した | 「デプロイ > デプロイを管理 > ✏編集 > バージョン：新バージョン」で更新する（URL は変わらない） |
| 端末を変えたら記録が見えない | 新しい端末でも設定画面で URL と合言葉を入力する（記録はスプレッドシートにあるので消えていない） |
| 体力テストの合計点が出ない | A のページで得点表（男子・女子）を選んでいるか確認する（選択は端末ごとに保存） |
